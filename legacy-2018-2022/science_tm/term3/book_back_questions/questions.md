## அலகு 1: நம்மைச் சுற்றியுள்ள பொருள்கள் (Unit 1: Materials Around Us)

### I. அடைப்புக் குறிக்குள் உள்ள சொற்களைக் கொண்டு கோடிட்ட இடங்களை நிரப்புக
(மரம், களிமண், உலோகம், ரப்பர், கல்)

1. பானைகள் மற்றும் செங்கற்கள் செய்ய உதவும் பொருள் _______ ஆகும்.
2. நாற்காலி, மேசை மற்றும் கதவுகள் செய்யப் பயன்படும் இயற்கை மூலம் _______ ஆகும்.
3. சிலைகள் மற்றும் கட்டடங்கள் செதுக்கப் பயன்படுவது கடினமான _______ ஆகும்.
4. வாகனங்களின் டயர்கள் மற்றும் அழிப்பான் (Eraser) செய்யப் பயன்படுவது _______ ஆகும்.
5. தங்கம், வெள்ளி, இரும்பு ஆகியவை _______ வகையைச் சேர்ந்தவை.

### II. சரியான விடையைத் தேர்ந்தெடுத்து எழுதுக

1. இயற்கையிலிருந்து நேரடியாகப் பெறப்படும் பொருள் எது?
   (அ) பிளாஸ்டிக்
   (ஆ) மரக்கட்டை
   (இ) நைலான்
   (ஈ) கண்ணாடி

2. நீரை உறிஞ்சாத, நெகிழும் தன்மையுடைய பொருள் எது?
   (அ) ரப்பர்
   (ஆ) பருத்தித் துணி
   (இ) காகிதம்
   (ஈ) சாக்பீஸ்

3. எளிதில் உடையக்கூடிய, ஒளி புகும் தன்மை கொண்ட பொருள் எது?
   (அ) கண்ணாடி
   (ஆ) இரும்பு
   (இ) மரக்கட்டை
   (ஈ) தோல்

4. மனிதனால் உருவாக்கப்பட்ட செயற்கைப் பொருள் எது?
   (அ) களிமண்
   (ஆ) பிளாஸ்டிக்
   (இ) பாறை
   (ஈ) மணல்

### III. பொருத்துக

1. களிமண் — (அ) மர நாற்காலி
2. மரக்கட்டை — (ஆ) மண்பானை
3. ரப்பர் பால் — (இ) கம்பளி ஆடை
4. செம்மறி ஆட்டு உரோமம் — (ஈ) வாகன டயர்
5. மணல் — (உ) கண்ணாடி பாட்டில்

### IV. நெகிழும் பொருள்கள் மற்றும் நெகிழாப் பொருள்களை வகைப்படுத்துக
(ரப்பர் வளையம், மரக்கட்டை, இரும்பு ஆணி, நெகிழிப் பை, கல், அழிப்பான்)

1. **நெகிழும் பொருள்கள் (Flexible):** _______, _______, _______
2. **நெகிழாப் பொருள்கள் (Rigid):** _______, _______, _______

### V. சரியா? தவறா? என எழுதுக

1. பிளாஸ்டிக் இயற்கையாக மண்ணில் மட்கிப் போகும் பொருள். _______
2. அனைத்து உலோகங்களும் பளபளப்பான கடினத் தன்மை கொண்டவை. _______
3. கம்பளி ஆடைகள் குளிர் காலத்தில் உடலை கதகதப்பாக வைத்திருக்க உதவுகின்றன. _______
4. நாம் மரங்களை வெட்டுவதைத் தவிர்த்து மரக்கன்றுகளை நட வேண்டும். _______

### VI. சுருக்கமான வினாக்கள்

1. இயற்கைப் பொருட்கள் என்றால் என்ன? இரண்டு எடுத்துக்காட்டுகள் தருக.
2. மனிதனால் உருவாக்கப்பட்ட பொருட்கள் இரண்டினைக் குறிப்பிடுக.
3. ரப்பரின் இரண்டு முக்கியப் பயன்பாடுகளைக் கூறுக.
4. பிளாஸ்டிக் பயன்பாட்டைக் குறைக்க நாம் என்ன செய்ய வேண்டும்?
5. கண்ணாடிப் பொருட்களைக் கையாளும்போது கவனமாக இருக்க வேண்டியது ஏன்?


## அலகு 2: எனது அருமைத் தாய்நாடு (Unit 2: My Beloved Motherland)

### I. கோடிட்ட இடங்களை நிரப்புக

1. நமது நாட்டின் தேசியக் கொடி _______ நிறங்களைக் கொண்டது. (மூன்று / நான்கு)
2. தேசியக் கொடியின் நடுவில் உள்ள அசோகச் சக்கரத்தில் _______ ஆரங்கள் உள்ளன. (24 / 20)
3. நமது நாட்டின் தேசிய விலங்கு _______ ஆகும். (புலி / சிங்கம்)
4. நமது நாட்டின் தேசியப் பறவை _______ ஆகும். (மயில் / கிளி)
5. நமது நாட்டின் தேசிய மலர் _______ ஆகும். (தாமரை / ரோஜா)
6. தமிழ்நாட்டின் மாநில மரம் _______ ஆகும். (பனை மரம் / வேப்ப மரம்)

### II. சரியான விடையைத் தேர்ந்தெடுத்து எழுதுக

1. நமது தேசிய கீதத்தை இயற்றியவர் யார்?
   (அ) பாரதியார்
   (ஆ) இரவீந்திரநாத் தாகூர்
   (இ) கவிமணி
   (ஈ) பாரதிதாசன்

2. நமது நாட்டின் தேசிய நதி எது?
   (அ) கங்கை
   (ஆ) காவிரி
   (இ) வைகை
   (ஈ) யமுனை

3. தமிழ்நாட்டின் மாநில விலங்கு எது?
   (அ) வரையாடு
   (ஆ) மான்
   (இ) யானை
   (ஈ) புலி

4. நமது தேசப்பிதா என்று அழைக்கப்படுபவர் யார்?
   (அ) மகாத்மா காந்தி
   (ஆ) நேரு
   (இ) சுபாஷ் சந்திர போஸ்
   (ஈ) காமராஜர்

### III. பொருத்துக

1. தேசிய விலங்கு — (அ) மயில்
2. தேசியப் பறவை — (ஆ) புலி
3. தேசிய மரம் — (இ) மாம்பழம்
4. தேசியப் பழம் — (ஈ) ஆலமரம்
5. தேசிய மலர் — (உ) தாமரை

### IV. தமிழ்நாட்டின் மாநிலச் சின்னங்களைப் பொருத்துக

1. மாநில விலங்கு — (அ) மரகதப்புறா
2. மாநிலப் பறவை — (ஆ) வரையாடு
3. மாநில மலர் — (இ) பனை மரம்
4. மாநில மரம் — (ஈ) செங்காந்தள்
5. மாநிலக் கனி — (உ) பலாப்பழம்

### V. சரியா? தவறா? என எழுதுக

1. தேசியக் கொடியை நாம் எப்போதும் மரியாதையுடன் நடத்த வேண்டும். _______
2. தேசியக் கொடியின் காவி நிறம் தியாகத்தைக் குறிக்கிறது. _______
3. காந்தி ஜெயந்தி அக்டோபர் 2 அன்று கொண்டாடப்படுகிறது. _______
4. நாட்டின் இயற்கை மற்றும் கலாச்சாரச் சின்னங்களை நாம் பாதுகாக்க வேண்டும். _______

### VI. சுருக்கமான வினாக்கள்

1. நமது தேசியக் கொடியில் உள்ள மூன்று வண்ணங்கள் யாவை?
2. தமிழ்நாட்டின் மாநிலச் சின்னங்கள் மூன்றினைக் குறிப்பிடுக.
3. நமது நாட்டின் தேசியப் பழம் மற்றும் தேசிய நதியின் பெயர்களைக் கூறுக.
4. நாம் நமது தேசத்திற்கு எவ்வாறு மரியாதை செலுத்த வேண்டும்?
5. சுதந்திரப் போராட்டத் தலைவர்கள் இருவரின் பெயர்களைக் கூறுக.


## அலகு 3: சக்தியின் பயணம் (Unit 3: Sakthi's Journey)

### I. நான் யார்? சரியான விடையைத் தேர்ந்தெடுத்து எழுதுக
(மிதிவண்டி, பயணிகள் தொடர்வண்டி, உலங்கு ஊர்தி/ஹெலிகாப்டர், படகு)

1. நான் எரிபொருள் இல்லாமல் கால்களால் மிதித்து இயக்கப்படுபவன்: _______
2. நான் அனைத்து ரயில் நிலையங்களிலும் நின்று பயணிகளை ஏற்றிச் செல்பவன்: _______
3. நான் குறைந்த எண்ணிக்கையிலான மக்களை ஏற்றிக்கொண்டு வானில் பறப்பவன்: _______
4. நான் ஆறு மற்றும் ஏரிகளில் மிதந்து மக்களை அக்கரைக்குக் கொண்டு செல்பவன்: _______

### II. போக்குவரத்து வாகனங்களை அவற்றின் பாதைகளோடு வகைப்படுத்துக
(மகிழுந்து, படகு, வானூர்தி, தொடர்வண்டி, மிதிவண்டி, கப்பல், உலங்கு ஊர்தி, சரக்கு ரயில்)

3. **வான்வழிப் போக்குவரத்து:** _______, _______
4. **தண்டவாளப் போக்குவரத்து (இருப்புப்பாதை):** _______, _______

### III. போக்குவரத்துக் குறியீடுகளும் சைகை விளக்குகளும் — கோடிட்ட இடங்களை நிரப்புக

1. போக்குவரத்து சைகை விளக்கில் சிவப்பு நிறம் ஒளிரும்போது நாம் வாகனத்தை _______ வேண்டும். (நிறுத்த / இயக்க)
2. மஞ்சள் நிற விளக்கு எரியும்போது நாம் புறப்படத் _______ இருக்க வேண்டும். (தயாராக / தூங்க)
3. பச்சை நிற விளக்கு எரியும்போது நாம் பாதுகாப்பாகச் _______ செல்லலாம். (சென்று / ஓடி)
4. பாதசாரிகள் சாலையைக் கடக்க _______ கோடுகளைப் பயன்படுத்த வேண்டும். (வரிக்குதிரைக் / சதுரக்)
5. இருசக்கர வாகனத்தில் செல்லும்போது நாம் கட்டாயம் _______ அணிய வேண்டும். (தலைக்கவசம் / தொப்பி)

### IV. பொருத்துக

### V. சரியா? தவறா? என எழுதுக

1. நாம் எப்போதும் நடைபாதையில் மட்டுமே நடந்து செல்ல வேண்டும். _______
2. ஓடும் பேருந்தில் படிக்கட்டில் நின்று பயணம் செய்வது பாதுகாப்பானது. _______
3. சாலை விதிகளைப் பின்பற்றுவது விபத்துகளைத் தவிர்க்க உதவும். _______
4. மிதிவண்டியில் பயணம் செய்வது உடற்பயிற்சியையும் தரும், காற்று மாசையும் தடுக்கும். _______

### VI. சுருக்கமான வினாக்கள்

## அலகு 4: பகலும் இரவும் (Unit 4: Day and Night)

### III. கோடிட்ட இடங்களை நிரப்புக

2. நண்பகல் வேளையில் நமது நிழல் மிகச் _______ இருக்கும். (சிறியதாக / பெரியதாக)

4. தன் உடலில் இருந்து தானாகவே ஒளியை உமிழும் பூச்சி _______ ஆகும். (மின்மினிப் பூச்சி / எறும்பு)
5. நிழல் உருவாக ஒளி புகாத ஒரு பொருளும் _______ ஆதாரமும் தேவை. (ஒளி / நீர்)

3. மல்லிகைப் பூ பகல் நேரத்தில் மட்டுமே பூக்கும். _______
4. காலையிலும் மாலையிலும் சூரியனின் சாய்ந்த கதிர்களால் நிழல் நீளமாகத் தெரியும். _______

## அலகு 5: வியத்தகு இயற்கை (Unit 5: Wonders of Nature)

### I. நான் யார்? எனக் கண்டுபிடித்து எழுதுக
(குறிஞ்சி மலர், நத்தை, தொட்டாற்சுருங்கி, பல்லி)

1. நான் பன்னிரண்டு ஆண்டுகளுக்கு ஒருமுறை மலையில் மலர்வேன்; நீல நிறமுடையவன்; என்னால் தான் நீலகிரி என்ற பெயர் உருவானது. நான் யார்? _______
2. எனக்கு இரண்டு இணை உணர்நீட்சிகள் உள்ளன; கண்கள் உணர்நீட்சியில் காணப்படும்; ஆபத்து வந்தால் என் உடலைக் கூட்டினுள் இழுத்துக் கொள்வேன். நான் யார்? _______
3. என்னை விரலால் தொட்டவுடன் எனது இலைகளைச் சுருக்கிக் கொள்வேன். நான் யார்? _______
4. எனது வால் துண்டிக்கப்பட்டாலும் சில நாட்களில் மீண்டும் புதிதாக வளரும். நான் யார்? _______

### II. சரியான சொற்களைக் கொண்டு கோடிட்ட இடங்களை நிரப்புக

3. பூச்சிகள் மலரிலிருந்து _______ உறிஞ்சுகின்றன.

5. _______ வால் துண்டிக்கப்பட்டாலும் மீண்டும் வளரும்.

### III. சரியான விடையைத் தேர்ந்தெடுத்து எழுதுக

   (அ) குறிஞ்சி
   (ஆ) ரோஜா
   (இ) மல்லிகை
   (ஈ) தாமரை

   (அ) ஆறு கால்கள்
   (ஆ) எட்டு கால்கள்
   (இ) நான்கு கால்கள்
   (ஈ) பத்து கால்கள்

3. வேர்க்கடலை எங்கு வளர்கிறது?

   (இ) தண்டுப் பகுதியில்

   (அ) கிரீட வடிவம்
   (ஆ) நட்சத்திர வடிவம்
   (இ) மணி வடிவம்
   (ஈ) தட்டு வடிவம்

### IV. பொருத்துக
