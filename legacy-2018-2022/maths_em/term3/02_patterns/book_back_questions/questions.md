## Questions

### I. Fill in the Blanks

1. 2, 4, 6, 8, _______, _______ is a number pattern formed by skip counting in 2s.
2. 5, 10, 15, 20, _______, _______ is a number pattern formed by skip counting in 5s.
3. 10, 20, 30, 40, _______, _______ is a number pattern formed by skip counting in 10s.
4. 1, 3, 5, 7, _______, _______ is a pattern of consecutive odd numbers.
5. 3, 6, 9, 12, _______, _______ is a pattern formed by skip counting in 3s.

### III. State True or False

1. In the sequence 2, 4, 6, 8, 10, all numbers are even numbers.
2. The sequence 100, 90, 80, 70 is an example of an ascending number pattern.
3. Number patterns can be created by repeatedly adding or subtracting a fixed number.
4. In the pattern 1, 4, 7, 10, the rule is to add 3 to each previous number.
5. The sequence 5, 10, 15, 25, 30 correctly skip counts in 5s throughout.
